# 高温设施规划 Agent

面向基层治理人员、责任规划师和规划咨询团队的高温设施规划 Agent，用于将自然语言高温治理目标转译为空间分析任务，并生成可审议的清凉设施布点方案。

## Demo

- 本地 Demo：`http://127.0.0.1:5175/`
- 启动方式：

```bash
npm install
npm run dev -- --port 5175
```

## 产品文档

- [正式 PRD](./PRD.md)

## 核心能力

- 自然语言治理目标解析；
- 高温风险、重点人群、设施覆盖和缺口识别；
- 候选点推荐与地图联动；
- 公平优先、效率优先、低成本优先、应急优先方案比选；
- 项目级规划记忆、连续追问和局部重算；
- 证据摘要、不确定性说明和人工核验清单。

## 技术栈

- Vite
- React
- MapLibre GL
- DeepSeek API 代理
- 本地空间数据 RAG

## 当前边界

当前版本用于验证高温设施规划 Agent 的产品流程和交互体验，空间分析数据以本地演示数据和 mock 工具为主。正式落地需接入真实 GIS、设施台账、人口数据、步行路网和现场核验流程。
