# 居民起点空间下沉方法与验证

## 研究目的

WorldPop 人口网格能够表达人口规模与年龄结构，但网格中心不必然对应住宅、社区出入口
或可进入步行网络的位置。直接以网格中心作为居民出发点，会造成起点落入水体、道路中央、
非居住用地或远离步行网络等空间偏差。

本项目将人口统计单元分级下沉为“住宅 POI 步行入口代理点”或“住宅建筑步行入口代理点”。
人口网格继续承担人口数量与人群类型权重，住宅 POI 和建筑轮廓提供居住空间语义，
EULUC 提供住宅用地语境核验，OSM 主步行网络提供可执行的路径入口。

## 技术流程

1. 读取 2,073 个 WorldPop 人口统计单元，保留 `unit_id` 与全部人群权重。
2. 清洗住宅 POI，剔除缺失坐标与超出研究范围的记录。
3. 仅保留距 OSM 主步行网络不超过 100m、且 250m 邻域内存在 EULUC 住宅用地的住宅 POI。
4. 海淀区内人口单元仅匹配区内住宅 POI及区内 OSM 节点，最大匹配半径为 750m。
5. 将住宅 POI 吸附到最近 OSM 主步行网络节点，形成可路径计算的入口代理点。
6. 未找到合格住宅 POI 的区内人口单元，匹配位于 EULUC 住宅地块、满足面积高度阈值且
   100m 内可接入 OSM 主步行网络的建筑入口代理。
7. 仍未找到合格代理的人口单元吸附到最近区内 OSM 节点，并标记为路网节点回退。
8. 重新计算海淀边界、EULUC 住宅语境、100m 路网可达性和主连通分量约束。
9. 使用人口权重抽样入口代理点，执行活动链、路径选择与逐道路边热暴露模拟。

## 建筑代理增量效果

| 指标 | 仅住宅 POI 分级 | 加入住宅建筑代理 |
|---|---:|---:|
| 正式可采样起点 | 1,225 | 1,443 |
| 正式可采样率 | 59.09% | 69.61% |
| 纯路网回退单元 | 864 | 517 |
| 区内人口单元具备住宅语境比例 | 65.40% | 77.04% |
| 正式验证样本中的纯路网回退首起点 | 2 | 0 |

建筑代理使更多人口单元具备可解释的居住空间依据。网格中心至入口代理点的中位位移由
149.22m 增至 213.08m，体现入口从就近道路转向具有住宅语义证据的位置。该位移变化需要
与居住语义提升共同报告。

100 个居民的正式验证运行生成 192 条活动。首活动起点中，91 个采用住宅 POI 步行入口代理，
9 个采用住宅建筑步行入口代理，纯路网节点回退为 0。OD 来源可追溯率、道路路径成功率和 100m 接入约束通过率
均为 100%。逐道路边距离、时间、暴露累计和节点连续性审查均为零失败。

## 解释边界

- 住宅 POI 步行入口代理点用于提升合成人口起点的空间合理性，不代表真实家庭住址。
- 建筑代理用途由 EULUC 住宅地块语境推断，仍需抽样核验建筑真实用途。
- OSM 节点未经过现场核验，可能位于小区周边道路，未必对应正式社区门。
- 路网节点回退单元缺少住宅 POI 支持，后续应优先结合建筑轮廓或社区出入口数据复核。
- 当前验证支持模型内部一致性与空间合理性，真实 OD 配对仍需轨迹、问卷或设施使用数据验证。

## 运行入口

完整流水线已经在 `scripts/run_planning_pipeline.ps1` 中接入起点下沉、约束复算、独立审查和
Agent 模拟。单独执行起点下沉与审查时使用：

```powershell
python scripts\build_residential_building_proxies.py
python scripts\downscale_population_origins_to_residential_poi.py
python scripts\prepare_euluc_agent_constraints.py --env-dir outputs\haidian\agent_env_residential_proxy
python scripts\audit_residential_proxy_origins.py
```
