# 行为验证、LLM 消融、设施运行与不确定性分析

## 模块定位

本轮改造用于回答四个问题：

1. 行为模拟在缺少真实问卷和轨迹时，可以量化验证到什么程度。
2. LLM 在受约束决策中提供了哪些增量，哪些稳定性来自结构化规则。
3. 清凉设施在容量、开放时间和居民使用概率约束下是否仍然有效。
4. 选址结论对关键参数变化是否稳健。

## 行为模拟量化验证

验证模块同时报告外部宏观校准与内部有效性。

内部有效性包括：

- 起点与目的地来源可追溯率；
- OSM 道路路径成功率；
- 活动目的与最大出行距离符合率；
- 行为动作是否属于相应出行类型允许的动作集合；
- 道路环境数据覆盖率；
- 首活动起点具备住宅 POI 或住宅建筑依据的比例。

当前 7 项内部检查全部通过，内部有效性得分为 100%。该分数反映模型内部一致性和空间合理性，
不能解释为真实行为预测准确率。

热压力与行为调整率的 Spearman 相关系数为 0.674，且 p<0.001，说明模型能够产生方向合理的
热响应梯度。

活动类别经过公开统计后分层校准后与目标分布一致。该结果证明校准机制能够工作，个体 OD、
出发时间、设施使用和热响应动作仍缺少外部观测验证。

### 多随机种子稳定性

使用 5 个随机种子、每次 50 个居民进行重复模拟。道路路径成功率始终为 100%。关键指标变异系数：

| 指标 | 变异系数 |
|---|---:|
| 人均活动数量 | 4.79% |
| 平均路径距离 | 6.93% |
| 平均活动热暴露 | 12.59% |
| 行为调整率 | 9.64% |
| 失效活动率 | 20.88% |
| 高风险或失效活动率 | 12.18% |

路径与活动数量较稳定。失效活动率对随机抽样更敏感，正式汇报应报告多次运行区间，
并避免仅依据单一随机种子解释失效活动数量。

## 受约束 LLM 决策与消融

LLM 仅在结构化模型允许的动作集合内选择动作。GIS 负责提供路径、热暴露、设施可达性和绕行时间，
LLM 无权生成地点、道路或数值。

消融实验采用 12 个同源活动，四组使用相同随机种子：

| 实验 | 规则合规率 | 与结构化模型动作分歧率 | 解释 |
|---|---:|---:|---|
| 结构化决策 | 100% | 0% | 基线 |
| 完整受约束 LLM | 100% | 0% | 完整上下文和结构化先验 |
| 移除空间上下文 | 100% | 0% | 当前小样本未检测到空间上下文增量 |
| 移除结构化先验 | 100% | 41.67% | LLM 决策明显变化 |

当前结果表明，受约束 LLM 的决策稳定性主要由结构化先验保障。LLM 的主要价值集中在复杂语境解释、
规则边界内的替代动作选择与参与式叙事。空间上下文贡献需要扩大活动样本并覆盖更多高热、高绕行和
设施不匹配情景后继续检验。

## 设施运行约束

设施反事实收益采用以下形式：

```text
实际干预效力
= 基础功能效力
× 开放时间匹配
× 使用概率
× 容量因子
```

使用概率由设施角色、公共性、功能类型和出行类型共同决定。容量因子为：

```text
容量因子 = min(1, 每小时服务容量 / 预期每小时需求)
```

模拟样本通过显式客流扩展系数转换为设施小时需求。该系数属于情景参数，不能解释为观测客流。

加入运行约束后，20 个平衡网络设施的内部需求覆盖率为 8.44%。容量与开放时间约束下，
活动服务覆盖率为 21.88%，平均设施使用概率约为 28.47%，开放时间匹配率约为 90.40%。

## 敏感性与不确定性

单因素敏感性分析覆盖：

- 服务半径：300m、500m、700m；
- 容量倍率：0.5、1.0、1.5；
- 使用概率倍率：0.7、1.0、1.3；
- 干预效力倍率：0.7、1.0、1.3；
- 模拟活动客流扩展倍率：0.5、1.0、2.0。

服务半径是覆盖率和活动恢复率最敏感的参数。使用概率与干预效力直接控制暴露削减幅度。
容量减半或客流扩展翻倍时，平均暴露削减从 0.266 降至约 0.239，表明容量约束能够被识别。

30 次蒙特卡洛实验结果：

| 指标 | 均值 | P05 | P95 |
|---|---:|---:|---:|
| 活动服务覆盖率 | 21.46% | 18.23% | 23.96% |
| 平均暴露削减 | 0.253 | 0.173 | 0.376 |
| 总暴露削减 | 48.54 | 33.19 | 72.24 |
| 失效活动恢复率 | 8.72% | 7.69% | 11.54% |
